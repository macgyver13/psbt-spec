How to interpret this report

Counts describe execution observations, not full conformance or positive/negative assertion coverage. Passed means the validator returned success; it does not prove the substantive condition was exercised. Expected errors are legacy assertions only; they are not asserted catalog outcomes. Legacy check mappings indicate candidate relevance only.

The Silent payments lens selects rule columns whose source evidence is BIP-352, BIP-374, BIP-375, or BIP-376. It filters columns only, keeps all vectors available, and does not turn validation off or implement future BIPs. Each fixture harness fixes the evaluated operation and enabled extension BIPs: bip174, bip370, and bip370_locktime use no extension BIPs; bip375 enables BIP-375; bip376 enables BIP-376; roles uses each fixture’s BIP list. These settings are not changed by view filters. Status filters events within cells, keeping rows and columns. Observation gaps: rules with no passed events or no failed events across the entire supplied dataset. Missing observations do not establish missing assertions or nonconformance.
